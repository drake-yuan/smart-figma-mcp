⚡ Auto Layoutify

Convert selected Frames from free-form layout to Auto Layout with one click. Enjoy zero-token compilation with dramatically improved output fidelity.

💡 Tips
• Select one or more Frames, then click Convert
• The plugin auto-infers main axis direction, spacing, and padding
• Converted Frames get a [Auto Layout] name suffix
• Ctrl+Z to undo conversion
• Recompile in Smart Figma MCP after conversion → zero tokens
